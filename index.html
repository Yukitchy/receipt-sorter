設定

キーはこの端末のブラウザ内（localStorage）にだけ保存され、レシート画像の読み取り時に Anthropic の API へ直接送られます。それ以外の場所へ送られることはありません。未設定でも手入力で全機能が使えます。

freee に登録している口座名と合わせてください。個人の財布から払った分は「事業主借」などに変えられます。

このアプリについて

レシート画像とデータはこの端末の中（IndexedDB）に保存されます。サーバーには送信されません。AI読み取りを使う場合のみ、画像が Anthropic の API に送られます。
